# Contentful App Setup for NT

## Required Content Types

NT requires 3 content types to be present in your Contentful environment. Verify via MCP:

```
mcp__contentful__list_content_types (filter: nt_)
```

### `nt_experience`

| Field | Type | Notes |
|-------|------|-------|
| `nt_experience_id` | Symbol | Auto-filled by NT from sys.id — do not set manually |
| `nt_name` | Symbol | Display name |
| `nt_description` | Text | Optional |
| `nt_type` | Symbol | `nt_experiment` or `nt_personalization` |
| `nt_config` | Object (JSON) | Experience config — generated by NT app |
| `nt_audience` | Link (Entry) → `nt_audience` | The audience for personalization |
| `nt_variants` | Array → Links (Entry) | Variant entries (same CT as baseline) |

### `nt_audience`

| Field | Type | Notes |
|-------|------|-------|
| `nt_audience_id` | Symbol | Auto-filled by NT from sys.id — do not set manually |
| `nt_name` | Symbol | Display name |
| `nt_description` | Text | Optional |
| `nt_rules` | Object (JSON) | Audience rule JSON — **REQUIRED** for LL-014 fix |

### `nt_mergetag`

| Field | Type | Notes |
|-------|------|-------|
| `nt_mergetag_id` | Symbol | Auto-filled by NT from sys.id |
| `nt_name` | Symbol | Display name |
| `fallback` | Symbol | Default value if no profile match |

## Creating NT Content Types via MCP

If these CTs don't exist in a new demo environment, create them. The CTs in `master` are the reference — check their structure and replicate.

**Publish order (always children first):**
1. Create and publish `nt_audience` entries
2. Create variant entries (the block type)
3. Create and publish `nt_experience` linking audience + variants

## NT App Installation in Contentful UI

1. Contentful → Apps → Marketplace → search "Ninetailed"
2. Install in your space
3. Configure with NT API key (use Development bucket key for demo envs)
4. The NT app adds UI panels to CT editors for experience management

## Data Bucket Setup

Two data buckets are available:
- **Main** — for production content (master env)
- **Development** — for all demo environments

Each bucket has its own API key. Don't mix them.

## Verifying NT is Connected

In Contentful UI → Apps → Ninetailed → should show connected status and your content types.

In your Next.js app, check browser console for:
```
[Ninetailed] Initialized with environment: main
[Ninetailed] Profile loaded: { id: '...', traits: {} }
```
